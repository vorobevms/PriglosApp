# PriglosApp — Пригласительное в Место Пряток

Текущая версия: 1.6.0, 15 встроенных дизайнов. Windows portable: `release-portable/Конструктор приглашений.exe`. Подготовлены отдельные команды `npm run build:win`, `npm run build:mac` (arm64, на Mac) и `npm run build:mac:x64`. Подробная актуальная инструкция переноса, сборки и проверки: [docs/macos-build.md](docs/macos-build.md). Разделы ниже описывают историю предыдущих версий.

macOS arm64: 14 октября 2026 packaged `.app` и `.dmg` собраны и вручную проверены пользователем (запуск, интерфейс, дизайны, загрузка фото, сохранение приглашения). Исправление Unicode-нормализации имени при запуске helper включено в Mac-конфигурацию. Подробнее: [сборка и проверка macOS](docs/macos-build.md).

Офлайн-приложение Electron для Windows 10/11 x64. Шаблон приглашения встроен в пакет, рядом с EXE ничего размещать не нужно.

## Использование

Добавьте фотографию, имя ребёнка, дату, время и локацию. Фото первоначально кадрируется по центру; перетаскивайте его прямо в рамке и меняйте масштаб колёсиком или кнопками − / +. «По центру» сбрасывает кадрирование. Минимальный масштаб заполняет рамку целиком, максимальный — 5×; пропорции фотографии сохраняются.

Время: 08:00–23:00 включительно, минуты с шагом пять минут. При выборе 23 часов доступны только 00 минут. «Скачать приглашение» открывает системный диалог сохранения JPEG с автоматически предложенным именем, например `Михаил_20 октября_19-00.jpg`. Отмена диалога не сохраняет файл.

Preview использует тот же полноразмерный canvas, что и экспорт JPEG (качество 0.97, 1080 × 1920). Размер на экране меняется только средствами CSS. Все данные обрабатываются локально; сетевые запросы интерфейса запрещены.

## Разработка и сборка

Node.js 22/24 LTS:

```sh
npm ci
npm test
npm start
npm run build
```

Переносимый Windows-файл: `dist/Приглашения 1.1.0.exe`. Старая сборка 1.0.0 не удаляется.

Проверка интерфейса: `node tests/smoke.cjs` (укажите `CHROMIUM_PATH` к Chrome либо установите браузер Playwright). Проверяет встроенный шаблон, минимальное окно без прокрутки, время, локации, перетаскивание и масштабирование, точное соответствие JPEG canvas и имя файла.

## Ресурсы и координаты

`assets/invitation-template.png` — исходный пользовательский шаблон 1080 × 1920. `assets/invitation-clean.png` — вариант с удалёнными буквами старого адреса. При отрисовке из него используется только область `addressRestore`: все остальные пиксели исходного шаблона сохраняются. Новые адреса накладываются обычным текстом, без плашки. Оба ресурса упаковываются Electron Builder в app.asar.

`assets/template-config.js` содержит координаты, наклон и размер маски фотографии, полный текст локаций и параметры переноса адреса. Старый демонстрационный SVG сохранён и не используется. Предыдущий шаблон из папки данных пользователя больше не загружается и не изменяется.

## Версия 1.2.0

Имя вводится сотрудником в нужном падеже; приложение меняет только регистр (первая буква заглавная, остальные строчные). Дата приглашения — например, «16 октября», без года. JPEG получает имя `ДР_Михаила_16 октября_19-00.jpg`.

Поворот фотографии: −30° … +30°, вокруг центра фотографии внутри прежней маски. «0°» сбрасывает только угол, «По центру» сбрасывает кадрирование целиком. Перетаскивание и масштаб работают совместно с поворотом. При вращении минимальный масштаб автоматически заполняет маску без пустых углов.

Новая сборка: `dist/Приглашения 1.2.0.exe`. Проверка сохранения из собранного Windows-приложения: `node tests/windows.cjs`.

## Версия 1.4.0

Название системного окна — «Конструктор пригласительных», окно остаётся 1040 × 740. Иконка воздушного шарика встроена в окно и EXE. Основной заголовок перенесён в шапку, кнопка «⚙ Настройки» открывает расширяемый раздел настроек.

Локации хранятся в `%APPDATA%/priglos-app/settings.json` (фактический путь возвращает Electron через `app.getPath("userData")`). Файл не зависит от временной распаковки portable EXE. SchemaVersion=1, locations — упорядоченный массив id/label/text; сохранение записывает временный файл и заменяет основной файл, сохраняя другие разделы настроек. Исходные Коньково/Алтуфьево создаются только при отсутствии файла. Повреждённый файл автоматически не заменяется.

Настройки позволяют добавлять, изменять, удалять с подтверждением и переставлять локации стрелками. До 100 локаций; название до 100 символов, текст до 2000. Многострочный текст сохраняется как введён пользователем; явные пустые строки сохраняются. Длинный текст переносится и уменьшается под блок адреса. Если список удалён целиком, экспорт отключён до добавления новой локации; пустой список не заменяется стартовыми адресами при следующем запуске.

«Обработка фото» раскрывает яркость, контраст, насыщенность и резкость. Нейтральные значения — 0. Сворачивание сохраняет обработку. «Сбросить» меняет только обработку, геометрия кадра сохраняется. «Авто» выполняет умеренную локальную коррекцию по среднему освещению и контрасту, без распознавания или ретуши лица. Обработка применяется в исходном разрешении фотографии и кэшируется. Очень большие фотографии могут обрабатываться дольше. Загрузка новой фотографии сбрасывает её обработку и геометрию; настройки обработки между запусками не сохраняются.

Каждое слово имени, разделённое пробелом, нормализуется отдельно. Имя и падеж не изменяются. Пример JPEG: `ДР_Воробьев Михаил_22 октября_19-40.jpg`.

Сборка: `dist/Приглашения 1.4.0.exe`. Дополнительные проверки: `node tests/features-smoke.cjs` и `node tests/native-settings.cjs`. Последняя использует отдельный профиль в dist и проверяет реальные файлы настроек после полного закрытия и запуска Electron. `node tests/windows.cjs` проверяет готовый Windows-пакет и запись JPEG. Доступ к внешней сети интерфейса остаётся запрещённым.

## Версия 1.5.0 — каталог дизайнов

`assets/template-config.js` содержит массив `window.templateConfigs`. Первый дизайн (portal / «Дизайн 1») использует неизменённый `assets/portal-template.png`, второй (balloons / «Дизайн 2») — `assets/balloons-template.png`, точную копию пустого «шаблон 3.png». Заполненный «шаблон 33.png» не включён в приложение. Названия пока временные.

Для нового дизайна добавьте фон в assets и объект в этот массив: уникальный id, title, background, width/height исходного PNG, photo и зоны name/date/time/address. Список выбора строится автоматически. Координаты заданы в пикселях полного фона. Фото поддерживает circle, arch, прямоугольник и произвольный локальный SVG maskPath; этот же путь используется для обрезки и попадания мыши. Цвет, семейство/насыщенность шрифта, выравнивание, градиент, обводка и тень задаются конфигурацией. Дополнительные встроенные шрифты подключаются через CSS @font-face и fonts (список CSS font для загрузки до отрисовки). Локации сохраняют ручные переносы, автоматически переносятся и уменьшаются под maxWidth/maxHeight; lineHeight задаёт интервал. Постоянные надписи второго фона не дублируются.

Единый src/render.js рисует оба дизайна в полном разрешении. Preview отображает тот же canvas, который кодируется в JPEG. Второй дизайн имеет арочную маску с контуром нижних облаков и шаров, встроенный Rubik (лицензия OFL в assets/fonts) и фиолетовое оформление имени. Растровый объёмный леттеринг демонстрационного имени приближен программным шрифтом с градиентом, обводкой и тенью, а не копируется как картинка.

Введённые данные, фото и обработка общие; кадрирование (масштаб, сдвиг, угол) хранится отдельно для каждого id на время текущего сеанса. Новый дизайн начинает с центрированного заполнения. Возврат восстанавливает кадр; загрузка новой фотографии сбрасывает кадрирование всех дизайнов. Настройки локаций и их постоянное хранилище не изменены.

Проверки: tests/designs-smoke.cjs сравнивает первый дизайн попиксельно с renderer версии 1.4 (fixtures), проверяет переключение, сохранение данных/обработки/кадров, маску и декоративные пиксели, имена, даты, адреса, разрешение и идентичность JPEG. tests/designs-windows.cjs проверяет оба дизайна из упакованного Windows-приложения, встроенные файлы и реальные JPEG через IPC. Переносимая сборка: dist/Приглашения 1.5.0.exe.
