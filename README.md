# Приглашения

Простое desktop-приложение для Windows. Фотографии и введённые данные обрабатываются только на компьютере. Интернет нужен разработчику для первой установки зависимостей и сборки; готовому приложению интернет не нужен.

## Запуск для разработки

Установите Node.js 22 или 24 LTS. Откройте терминал в папке проекта:

```sh
npm ci
npm start
```

## Сборка Windows

На Windows в папке проекта выполните:

```sh
npm ci
npm test
npm run build
```

В папке `dist` появится переносимое приложение «Приглашения … .exe». Его можно скопировать на компьютер Windows 10/11 x64 и запустить без установки Node.js. Установщик пока не предусмотрен. Приложение не подписано цифровой подписью; Windows может показывать предупреждение SmartScreen.

## Как пользоваться

При первом запуске выберите пустой шаблон PNG/JPG, присланный в чате, в поле «Шаблон приглашения». Локальная копия сохраняется в папке данных приложения Electron (на Windows — `%APPDATA%/priglos-app`). При следующих запусках он загрузится автоматически. Затем выберите фотографию, введите имя в нужной форме (например, «Всеволода»), дату и время. Предпросмотр обновляется автоматически. Выберите PNG или JPG, нажмите «Сформировать приглашение» и укажите место сохранения. Отмена диалога не сохраняет файл. Данные не сохраняются между запусками.

## Замена шаблона

Координаты настроены под присланный неоновый шаблон 1080 × 1920: имя внутри овальной рамки, дата и время рядом с подписями, фотография в наклонной рамке справа. Исходный файл изображения из чата не был доступен в рабочей папке, поэтому он выбирается локально в интерфейсе. Пиксели оформления не воссоздаются и не изменяются. Старый `assets/template.svg` сохранён только как предыдущая демонстрация и больше не используется.

Все настройки находятся в `assets/template-config.js`:

- `background` — по умолчанию `null` (шаблон выбирается в приложении). Для встроенного файла укажите `../assets/template.png` и добавьте сам файл в `assets`; сохранённый пользователем шаблон имеет приоритет;
- `width`, `height` — базовая система координат 1080 × 1920. Изображение с теми же пропорциями, но большим разрешением, экспортируется в своём исходном размере;
- `photo`: `x`, `y` — верхний левый угол области, `width`, `height` — размер, `radius` — скругление (0 для прямоугольника), `rotation` — угол в градусах вокруг верхнего левого угла (−18 для наклонной рамки);
- `name`, `date`, `time`: `x`, `y` — центр текста, `fontSize` — размер шрифта, `maxWidth` — допустимая ширина текста, `color` — цвет.

Все координаты задаются в базовой системе 1080 × 1920 и автоматически масштабируются под разрешение файла. `align` задаёт выравнивание текста, `uppercase` — заглавные буквы имени. Текущие координаты предварительно определены по изображению в чате и могут потребовать небольшого уточнения по исходному файлу. Фотография кадрируется по центру по принципу cover, без растягивания. Длинный текст автоматически уменьшается. Предпросмотр масштабируется только средствами интерфейса; PNG/JPG создаётся в полном разрешении, исходного файла шаблона. После замены ресурсов пересоберите приложение.

## Проверки

`npm test` проверяет кадрирование горизонтальных и вертикальных фотографий. `npm run build` собирает Windows-приложение. Для проверки интерфейса разработчиком предусмотрен `node tests/smoke.cjs` (требуется `npx playwright install chromium`).

Electron использует изолированный интерфейс без Node.js; сохранение производится через ограниченный мост и системный диалог. Внешние страницы и сетевые запросы интерфейса запрещены. Шаблоны, шрифты и ресурсы локальны, внешних API и серверной части нет.

## Выбор адреса

В поле «Место проведения» доступны только два готовых адреса из предоставленных изображений:

- ТЦ Маркос Молл / Алтуфьевское шоссе, / д.70к1, 2 этаж
- м. КОНЬКОВО, / 2 ВЫХОД / ПРОФСОЮЗНАЯ 109, К2

Адрес сразу отображается в предпросмотре и включается в PNG/JPG. Свободный ввод адреса не предусмотрен. Тексты находятся в `venues` файла `assets/template-config.js`, координаты и оформление — в `address`. Поскольку исходный шаблон уже содержит первый адрес, его текстовая область закрывается тёмной плашкой перед нанесением выбранного адреса. Значок геолокации остаётся виден. Для полностью чистого шаблона можно убрать настройку `address.cover`.
